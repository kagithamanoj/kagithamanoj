## Featured projects

- **[ai-agent-toolkit](https://github.com/kagithamanoj/ai-agent-toolkit)** — a small, readable toolkit for building LLM agent systems. Seven modules, each one file: tool-calling loop, RAG chain, multi-agent pipeline, conversational memory, QA evaluator, web scraping helper, workflow runner.
- **[llm-usage-tracker](https://github.com/kagithamanoj/llm-usage-tracker)** — tiny dependency-free Python library and CLI for tracking LLM token usage and cost across OpenAI, Anthropic, and Google.
- **[k8s-ready-check](https://github.com/kagithamanoj/k8s-ready-check)** — CLI that checks Kubernetes workload manifests for production-readiness basics (probes, resources, image tags, security) before rollout.
- **[openapi-breakcheck](https://github.com/kagithamanoj/openapi-breakcheck)** — catch breaking API changes before they ship. Diffs two OpenAPI 3.x specs and reports removed paths, newly-required params, narrowed enums, and more.
- **[k8s-cost-snapshot](https://github.com/kagithamanoj/k8s-cost-snapshot)** — estimate monthly Kubernetes cost per namespace from resource requests. No billing integration needed.
